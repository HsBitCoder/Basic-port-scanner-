# Basic port scanner.
 A lightweight, multithreaded TCP port scanner written in Python. 
Built as a personal project to understand how network reconnaissance 
tools work at a low level.

## Features
- Multithreaded scanning for speed
- Hostname resolution to IP
- Input validation and error handling
- Works on Windows and Linux

## Requirements
- Python 3.x
- No external libraries — standard library only

## Usage
Run the script and follow the prompts: 
Enter a target hostname or IP and the number of ports to scan.
